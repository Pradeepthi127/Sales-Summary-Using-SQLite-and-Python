# Task 7: Basic Sales Summary using SQLite and Python

## Objective
Use SQLite and Python to query simple sales data, summarize quantity and revenue per product, and display it as a bar chart.

## Tools Used
- Python
- SQLite (sqlite3)
- Pandas
- Matplotlib
- Jupyter Notebook

## What I Did
- Created a small SQLite database `sales_data.db`
- Created a `sales` table and inserted dummy data
- Ran a SQL query to compute total quantity and revenue for each product
- Used Pandas to load and display results
- Used Matplotlib to visualize revenue by product in a bar chart
- Saved the chart as `sales_chart.png`

## Output
- Tabular summary of product sales
- Revenue bar chart for each product
